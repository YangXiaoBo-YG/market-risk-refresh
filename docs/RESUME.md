# 简历与面试：市场风险观察站

## 项目定位

个人金融与 AI 产业研究产品｜产品负责人、研究问题设计与 Agent 协作编排｜React / TypeScript / GitHub Actions。

## 可用于简历的表述

- 从金融市场与 AI 产业研究需求出发，主导指标体系、来源口径和交互设计，组织 Agent 辅助调查、数据复核及实现，形成公开可访问的研究看板。
- 提出 MOVE 与 SPX 回撤的联动 / 背离观察问题，设计共同交易日对齐、历史分位与累计回撤视图，并通过等权 / 加权、滚动 Z-score 和自由比较支持假设探索。
- 将来源调查、独立复核、研究方法、工程实现和 UI 验收拆成可交付任务；以来源证据、异常场景和结果检查约束 AI 输出。
- 建立 GitHub Actions 每两小时检查来源、增量保存历史和静态站发布的链路，处理单来源失败及旧值保留，区分检查时间和实际观测日期。

## 个人贡献与协作归属

项目负责人的贡献是研究问题、产品判断、口径取舍、任务编排和验收；AI 协助资料搜集、代码与界面实现。不要将 Agent 辅助开发写成全部独立手写，也不要把脚本定时执行写成自主 Agent 常驻运行。

## 面试可以展示的证据

| 想展示的能力 | 可以直接打开的证据 |
