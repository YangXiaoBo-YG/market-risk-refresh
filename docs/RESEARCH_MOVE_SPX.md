# MOVE × SPX：把研究问题做成交互工具

## 研究动机

由项目负责人提出的观察问题是：债市波动压力抬升时，权益市场是否同步承压？是否也存在债市高压、股指仍接近高点的背离？产品把这个问题变成可切换时间区间、回查日期和观察反例的图表，而不是只给一句“二者反比”。

MOVE 反映美国国债期权隐含收益率波动；指标定义可回查 [ICE 官方介绍](https://ir.theice.com/press/news-details/2019/Intercontinental-Exchange-Completes-Acquisition-of-the-Merrill-Lynch-Option-Volatility-Estimate-MOVE-Index-from-Bank-of-America-Merrill-Lynch/default.aspx)。网页实际序列来自项目标注的第三方接口，不能将其等同于获得 ICE 商业数据授权。

## 当前已实现的研究工具

| 功能 | 方法 | 代码 |
|---|---|---|
| 同日比较 | 只对齐 MOVE 与 SPX 的共同观测日期 | `web/lib/move-comparison.ts` |
| SPX 回撤 | `100 × (当日值 / 此前累计最高值 − 1)`，包含当日高点 | `web/lib/risk-methods.ts` |
| MOVE 历史位置 | 过去一年窗口的经验分位，含当日、不含未来；窗口不足留空 | `web/lib/move-comparison.ts` |
| 同期压力与背离 | 总览固定规则 MOVE > 120 且 SPX 回撤 ≥ −2%；专题允许改变观察阈值 | `web/lib/risk-methods.ts`、`web/app/long-cycle.tsx` |
| 展示稳定性 | 分栏独立纵轴、共用日期；缩放区间不重置此前历史高点 | `web/app/long-cycle.tsx` |

这些是研究工具和描述规则，不是经样本外验证的交易信号。图形反向、阈值触发或同期背离都不足以证明稳定反比、预测能力或因果关系。

## 怎样进一步检验“负向关系”

以下是验证设计，尚未作为本仓库新增实证结果发布：

1. 固定样本起止与数据快照，对齐共同交易日，记录缺失和来源修订。
2. 分别比较 SPX 收益率与 MOVE 变化、SPX 回撤与 MOVE 水平。避免只对两个有趋势的水平序列计算相关就宣称发现规律。
3. 同时报告 Pearson / Spearman、滚动窗口和不同市场阶段，保留关系转弱、转正的区间。
4. 若讨论领先性，用 t 日信息研究之后的收益或回撤，明确预测窗口和非重叠 / 重叠样本处理；不得使用未来高点或未来分位定义当时信号。
5. 固定阈值和训练区间后做样本外检查，报告事件数量、收益分布、误报及基准；多次调参和试多个窗口要记录，避免只展示最漂亮的一组。
6. 因果机制需额外识别设计，不能由图表或简单相关推出。

## 简历应怎样表达

可以写：**提出 MOVE 与 SPX 回撤的联动及背离观察问题，将其操作化为共同交易日对齐、历史分位和回撤指标，并实现可交互的研究面板。**

不应写：发现 MOVE 与 SPX 稳定反比；预测市场下跌；实现某个准确率。当前代码和验证记录不支持这些结论。
